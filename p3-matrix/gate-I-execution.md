## 1. Core Execution Vectors

### # Vector 1: Predictability (Evaluation Parameter P_1)
Predictability analyzes live algorithmic execution speed and input variance over continuous, high-intensity testing cycles inside the containerized sandbox environment.
*   **The Compliance Threshold:** The candidate's typing cadence, syntax generation, and architectural design pacing must show a smooth, predictable flow trajectory.
*   **The AI-Hacking Volatility Indicator:** Erratic pacing spikes, rapid structural out-of-sequence changes, or heavy block insertions of unverified code indicate structural panic or systemic copy-pasting from generative engines. This erratic telemetry triggers automatic calibration penalties.

### # Vector 2: Performance (Evaluation Parameter P_2)
Performance evaluates micro-execution computational efficiency, system runtime characteristics, and resource consumption parameters under deep load variables.
*   **The Compliance Threshold:** Custom software architectures must adhere to strict mathematical conservation laws, demonstrating clean processing pipelines that prevent algorithmic waste.
*   **The Resource Exhaustion Indicator:** Systems that show unexplained memory footprint expansion, inefficient loops scaling linearly, or state leakage patterns across modular boundaries fail the operational requirement.

### # Vector 3: Productivity (Evaluation Parameter P_3)
Productivity quantifies the sustained structural clarity and algorithmic soundness of code changes during sandboxed compilation cycles.
*   **The Compliance Threshold:** Every incremental iteration step must move the code base forward smoothly toward total system resolution without introducing regression loops.
*   **The Structural Decay Indicator:** Continuous compilation crashes, chaotic variable adjustments, and a reliance on trial-and-error debugging telemetry indicate an absence of baseline architectural foresight.
